# ₩10만 Wall — 슬라이스 5–9 Implementation Plan

> **For agentic workers:** TDD 세로 슬라이스. 커밋은 사용자가 그 턴에 명시한 뒤에만.

**Goal:** 라이선스가 출하 경로에 실리고, 만료 벽이 차를 그리지 않으며, LIVE 연료 링·Swift 동의 전 테일·문서 숫자가 같은 사실을 말한다.

**Architecture:** 서버 없음. Stripe 없음. 라이선스는 조직 설정 파일의 `license` 칸. Swift는 메시지 핸들러로만 테일을 연다.

**Tech Stack:** TypeScript · Vitest · existing Swift WKWebView

**Spec:** `docs/superpowers/specs/2026-09-01-100k-subscription-prd.md` W2–W5, v2.0 §4.5 · §11.2, crosscheck L2–L4 · §3 문서.

## Global Constraints

- 런타임 의존성 0. `as any` 금지. 실패 테스트 삭제 금지.
- 개인 간 사용량 정렬 금지.
- Stripe / Developer ID / 약관 본문 / LiteLLM / 8시간 힙 실측 / G1 사람 테스트 **하지 않음**.
- 커밋은 사용자가 그 턴에 명시한 뒤에만.

## Rulings (사용자 결정 아님)

1. 라이선스 파일 = 기존 `pitwall.settings.json`의 `license` 키. `pricingOverride`와 같은 조직 파일. 로컬 설정으로 자가 발급 금지.
2. 만료 `hidden`은 타워뿐 아니라 트랙·모델 판 차량도 비움. 문구는 타워 aggregate.
3. 연료 링은 `fuel_pct`가 숫자일 때만 보임. 대시 게이지를 새로 만들지 않음.
4. Swift `isInspectable`은 DEBUG만 true.
